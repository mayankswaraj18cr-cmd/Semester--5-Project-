# Network Route Optimizer

An interactive, mobile-friendly demonstration of Dijkstra's shortest-path algorithm for finding the lowest-cost route through a weighted network.

## Overview

Network Route Optimizer makes Dijkstra's algorithm easier to understand by animating its decisions on a visual graph. It shows visited nodes, tentative distances, the selected shortest path, and a step-by-step execution log.

## Features

- Visualizes a weighted network and its shortest route.
- Animates the algorithm's node visits and distance updates.
- Displays final distances, route cost, and an execution log.
- Runs directly in a browser with no build step or dependencies.
