▸ Network Graph

A → C → D
Total Cost = 3

▸ Edge Weights

A → B4
A → C2
B → D5
C → D1

▸ Algorithm Steps

StepAction
1Assign source = 0, all others = ∞
2Select unvisited node with minimum distance
3Update neighboring node distances
4Repeat until all nodes are visited

▸ Time Complexity

Basic Array ImplementationO(V²)
Priority Queue ImplementationO((V+E) log V)

▸ C++ Source Code

#include<iostream>
using namespace std;

int main()
{
    int graph[4][4] =
    {
        {0,4,2,0},
        {4,0,0,5},
        {2,0,0,1},
        {0,5,1,0}
    };

    int dist[4]={0,999,999,999};
    bool visited[4]={false};

    for(int i=0;i<4;i++)
    {
        int min=999,u;

        for(int j=0;j<4;j++)
        {
            if(!visited[j] && dist[j]<min)
            {
                min=dist[j];
                u=j;
            }
        }

        visited[u]=true;

        for(int v=0;v<4;v++)
        {
            if(graph[u][v] &&
               dist[u]+graph[u][v]<dist[v])
            {
                dist[v]=dist[u]+graph[u][v];
            }
        }
    }

    cout<<"Shortest Distance A->D = "
        <<dist[3];

    return 0;
}
